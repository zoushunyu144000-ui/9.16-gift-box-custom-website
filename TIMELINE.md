# Timeline

## 预计总周期
约 2–3 周。

### Phase 1 — Requirement & Reference
- 梳理业务流程
- 确认 category / product / payment
- 收集品牌素材
- 收集参考网站

### Phase 2 — UI Design
- 页面结构
- Homepage
- Category
- Product detail
- Cart
- Checkout
- 关键 mobile screens

UI direction 通过后：
- 客户支付 50% deposit
- 进入正式开发

### Phase 3 — Development
- Frontend
- Product data
- Admin
- Cart / Checkout
- WhatsApp integration

### Phase 4 — Payment Gateway
- Gateway integration
- Payment success flow
- Payment failure flow
- Order creation
- Amount verification

### Phase 5 — QA / Acceptance
重点测试：
- Product / variant
- Cart
- Checkout
- Payment
- Success / fail states
- Mobile responsive
- Admin editing

客户实际体验并确认无问题后：
- 支付剩余 50%
- 正式交付

## 注意
第三方 Payment Gateway 商户审核时间不计入开发周期。
