## Client Preference
Core direction:
**Luxury + Clean**

Confirmed visual constraints:
- Predominantly light, refined base
- Warm ivory / cream / champagne preferred
- Near-black mainly for typography / controls
- Do **not** make the website black or dark
- Do not make it overly pink / feminine
- Mature, clean, premium, commercially usable
- Real independent-brand ecommerce feeling

## Critical Logo Clarification
The client supplied a black/gold AI-generated Moire Co. logo reference.

Important:
- Client has **no original vector/source logo**.
- The logo was generated casually with AI.
- After sharing it, the client explicitly said **"不要黑色" / do not use black**.
- Therefore the black background and 3D metal rendering are **not** website direction references.

Use the logo only to extract useful brand DNA:
- flowing calligraphic M
- continuous stroke feeling
- thin/thick tension
- upward movement
- one four-point star
- champagne warmth
- controlled light

## Current Working Direction
### LINE & LIGHT

A light premium ecommerce system built from:
1. **The Line** — one restrained continuous champagne curve derived from the M
2. **The Point** — one restrained four-point star used as punctuation / state / motion endpoint

The goal is:
**Art-directed premium commerce**, not an art website.

Festive:
- Priority directly below Hero
- Approx. 3–4 visible products
- image + name + RM price
- mobile must show product imagery
- horizontal featured-collection feeling

Fixed Gift Collection:
- Official business name must remain visible
- Real purchasable products
- Optional simple name personalisation / engraving only

Wine & Spirits:
- Must read as a purchasable category, not only lifestyle imagery

Corporate:
- Semi-curated = internal selection path based on existing / fixed products
- Fully Customised = custom enquiry path; Enquiry Now → WhatsApp
- `MADE FOR YOUR BRAND` should primarily belong to Fully Customised

## Art-Direction Problems to Avoid
- Generic Shopify
- Pinterest beige / quiet luxury
- Figma portfolio exercise
- Repeated text-left / image-right layouts
- Equal vertical padding on every section
- Tiny editorial metadata
- excessive numbering / badges / edition labels
- oversized brand watermarks
- wedding / romantic styling
- excessive flowers / ribbons / props
- fake European mansion / cellar imagery
- unrelated brand names inside product images
- photography overpowering ecommerce clarity

## Photography Direction
The next Stitch pass should use one coherent product-photography language.

Prioritize:
- product-dominant composition
- consistent packaging family
- clean light-neutral environment
- controlled directional light
- strong crop / texture / product scale
- very few props

Avoid:
- dried flowers everywhere
- candles
- lavender / eucalyptus
- travertine podium cliché
- fireplaces / arches / wine cellars
- wax seals / excessive ribbons
- fake brand logos
- culturally wrong seasonal props

## Motion Direction
Motion is allowed and encouraged only when it improves the premium feel.

Good candidates:
- Hero image reveal
- typography reveal
- restrained logo/line reveal
- product hover
- native collection rail
- Corporate process-line animation
- header / cart / search transitions

Avoid:
- long intro
- scroll hijacking
- heavy parallax
- 3D spinning logo
- particles
- repeated sparkle
- gold glow
- motion for every element
