# Scope & Pricing

> Last synced: 2026-09-26

## Agreed Project Price
**RM1500**

This is the agreed website design + development fee.

## Included
- Custom UI design
- Mobile-first storefront
- Homepage seasonal logic
- Festive Collection
- Fixed Gift Collection
- Wine & Spirits
- Corporate Orders
- Product listing / product detail
- Cart
- Checkout
- Online payment integration
- Admin product management
- Order management
- Product image upload
- Price / content editing
- Engraving / light customisation support
- WhatsApp enquiry flow
- Testing before handover

## Not Included
Third-party costs are paid separately by the client:
- Domain
- Hosting / server paid plan
- Database / storage paid upgrades
- Payment gateway charges / transaction fees
- Any future paid external service

Initial Supabase usage is planned on the free tier where sufficient.

## Payment Terms
### Before formal development
1. Confirm requirements
2. Confirm visual / colour direction
3. Produce first Homepage UI direction
4. Client approves overall UI direction

### Deposit
Once the first UI direction is approved:
- **50% deposit = RM750**
- Formal detailed design + development begins

### Final Payment
After:
- Website completed
- Core functions tested
- Payment flow tested
- Client acceptance completed

Client pays:
- **Remaining 50% = RM750**

## Change Scope
Minor refinement inside the agreed scope is included.

New major features, structural changes, or substantial post-approval changes may require separate quotation.
